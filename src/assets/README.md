# src/assets

Use this folder for source assets that get processed by the Vite build
(e.g. SVGs imported directly into components, local fonts).

Product, collection, gifting, bags, and sustainability photography lives
in `public/images/` instead, since those are referenced by plain URL
paths (e.g. `/images/products/eco-spring-bottle-duo.jpg`) rather than
imported into JS — that's why `public/` is the right place for them,
not this folder.
